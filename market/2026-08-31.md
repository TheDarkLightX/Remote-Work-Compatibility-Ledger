# Market scan — 2026-08-31

This note records why the current benchmark track was selected. It is not a claim that every linked job remains open indefinitely.

## Recurring task primitives observed

Across current remote/flexible AI-evaluation and quality roles, the strongest recurring primitives are:

1. define evaluation criteria for ambiguous model qualities;
2. construct evaluation datasets and adversarial cases;
3. evaluate model outputs for correctness, relevance, grounding, robustness, and policy/specification compliance;
4. identify failure modes and regressions;
5. separate model failures from evaluator/harness/data failures;
6. aggregate qualitative and quantitative evidence into a legible report/dashboard;
7. create structured datasets and machine-readable outputs;
8. improve prompts/workflows based on measured failures;
9. communicate results clearly to technical and nontechnical reviewers.

## Selection decision

The first project is **EVAL-001: LLM Regression Sentinel**.

Why it has high expected value:

- maps to both low-barrier evaluator work and higher-ceiling evaluation-engineering work;
- exercises judgment, QA, data handling, Python, metrics, experiment design, and communication;
- can be built efficiently with Codex/AI while preserving explicit human verification tasks;
- produces a reusable harness that later benchmarks can extend rather than discard;
- creates an artifact a reviewer can run instead of merely reading a claim.

## What this scan does not prove

A portfolio benchmark does not bypass employer-specific legal, identity, location, clearance, interview, or credential gates. Its purpose is narrower: maximize the strength and inspectability of the **task-competence signal** so that lack of evidence is not the reason for rejection.
